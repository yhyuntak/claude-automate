# Angel/Devil 범용 사고 도구 전환

> 개발 특화 → 범용 사고 도구로 전환

---

## 배경

현재 Angel/Devil은 개발(코드, 설계, 아키텍처)에 특화되어 있다.
사용자는 이직 결정, 사업 아이디어, 학습 계획, 글쓰기 등
**어떤 주제든** 비판적/확장적 사고 도구로 사용하고 싶어한다.

개발은 적용 사례 중 하나일 뿐, 핵심은 **사고 방식 자체**.

---

## 변경 대상 (6개 파일)

### 1. agents/devil.md - 범용 비판적 사고 도구

**변경 포인트:**
- 역할: "설계/구현의 허점을 찾는 비판적 검증자" → "어떤 아이디어/계획/결정이든 허점을 찾는 비판적 사고 도구"
- 핵심 질문: 유지 (이미 범용적 — "정말 이게 맞아?", "숨겨진 리스크는?")
- 입력: "설계 문서, 구현 계획, 아키텍처 결정, 코드 변경 사항" → "아이디어, 계획, 결정, 글, 전략 등 어떤 주제든"
- 성격: "현실 직시" 부분에서 "이상적인 설계보다" → "이상적인 계획보다"
- 질문 스타일: 개발 특화 AskUserQuestion 예시(성능, 동시성, 테스트 불가) → 범용 예시(실현 가능성, 숨겨진 비용, 대안 존재, 근거 부족)
- 출력 형식: 유지 (이미 범용적 구조)
- 사용 예시: 개발 예시 외에 비개발 예시 추가 (이직, 사업, 학습 등)
- "새벽 3시에 뭐가 깨져?" → "최악의 시나리오는?" (범용화)
- "과잉 설계 아니야?" → "과잉 계획 아니야?" (범용화)
- description: "냉철한 비판자. 계획/설계/코드 검증" → "냉철한 비판자. 어떤 아이디어든 비판적으로 검증"

### 2. agents/angel.md - 범용 확장적 사고 도구

**변경 포인트:**
- 역할: "사용자의 아이디어를 확장하고" → 유지 (이미 범용적)
- 성격: 유지 (이미 범용적)
- 질문 스타일: "더 큰 규모(10배 많은 사용자/데이터)" → "더 큰 규모(10배 스케일)"
  - "완전 자동화(사람 개입 없이)" → 유지
  - "실시간(즉시 반영되게)" → "즉시(시간 제약 없이)"
- 출력 형식: "영감: {어디서 - 게임, 분산시스템 등}" → "영감: {어디서 - 다른 도메인, 역사, 자연 등}"
- 사용 조건: "기술적 막힘" → "막힘" (기술 제거)
- description: "생각 확장자. 새로운 관점과 가능성 탐색" → 유지 (이미 범용적)

### 3. commands/devil.md - description 업데이트

**변경:**
- description: "냉철한 비판자. 계획/설계/코드를 검증" → "냉철한 비판자. 어떤 아이디어든 비판적으로 검증"
- 키워드: 기존 유지 + "비판적 사고" 추가

### 4. commands/angel.md - description 업데이트

**변경:**
- 현재 이미 범용적이라 최소 변경
- 키워드: 기존 유지

### 5. skills/brainstorm/refs/angel-devil.md - 호출 기준 범용화

**변경:**
- "기술적 실현 가능성이 불확실할 때" → "실현 가능성이 불확실할 때"
- 전체적으로 개발 특화 표현 제거

### 6. skills/planning/refs/devil-usage.md - 호출 기준 범용화

**변경:**
- "구현 방식에 리스크가 있을 때" → "방식에 리스크가 있을 때"
- planning 컨텍스트에서의 devil 사용은 유지 (planning 자체가 구현 계획이므로)

## 변경 원칙

1. **최소 변경**: 이미 범용적인 부분은 건드리지 않는다
2. **개발 = 예시 중 하나**: 개발 예시를 삭제하지 않고, 비개발 예시를 추가
3. **핵심 구조 유지**: 출력 형식(🟢🟡🔴), 질문 스타일, 판정 기준은 유지
4. **키워드 유지**: 기존 트리거 키워드는 그대로 유지
