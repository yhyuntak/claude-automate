## Problems & Solutions

- **아키텍처 설계**: 프로젝트 특화 에이전트(llm-evaluator, ux-consultant, idea-suggester)를 각 프로젝트에 유지하되, 공통 파이프라인은 claude-automate에서 관리 → 멀티 프로젝트 지원과 재사용성 확보 가능

## Decisions

1. **verify-web-ui 통일**: 모든 웹 UI 검증을 `/verify-web-ui`로 통일, `/verify`는 미래 범용 검증용으로 예약

2. **4단계 파이프라인**:
   - test-planner (전략): 테스트 계획 수립
   - verify-web-ui (조율): 스크린샷 분석 및 체크리스트 생성
   - 특화 에이전트 (분석): 프로젝트별 LLM 평가, UX 검토, 아이디어 제안
   - Reporter (통합): 최종 리포트 생성

3. **verify-flows 개념**: 각 프로젝트의 `.claude/verify-flows/` 디렉토리에 테스트 플로우 정의
   - `onboarding.md`: 신규 사용자 온보딩 플로우 테스트
   - `learning.md`: 학습 모드 플로우 테스트
   - 프로젝트별 커스터마이제이션 가능

4. **특화 에이전트 배치**: 프로젝트별 고유한 검증 로직(llm-evaluator, ux-consultant, idea-suggester)은 각 프로젝트에서 관리, claude-automate는 공통 파이프라인만 제공
