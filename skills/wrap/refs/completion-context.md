# 종료 컨텍스트 템플릿

## 공통 헤더

```
# Session: {task-name} (YYYY-MM-DD)

## 상태: 완료
## Plan: .claude/plans/{date}-{slug}.md
## 다음 행동: /start-work로 새 태스크 선택
```

---

## 본문

```
## 완료 내용
- {무엇을 만들었는가 — 구체적인 산출물}

## 주요 결정
- {설계/구현에서 내린 결정 + 근거}

## 남은 작업
- {이 태스크와 관련해 추가로 할 수 있는 것 — 없으면 "없음"}
```

---

## 작성 지침

- **완료 내용**: 파일명, 함수명 등 구체적인 산출물 나열. "구현했다" 같은 추상적 표현 금지.
- **주요 결정**: 선택지가 있었고 이유가 있는 결정만 기록. 자명한 내용 제외.
- **남은 작업**: 이번 태스크 범위에서 미처 못 한 것. 새 백로그 아이디어가 있으면 포함.
- **Plan 경로**: plan 파일이 없었던 경우 `## Plan: (없음)`으로 기재.
