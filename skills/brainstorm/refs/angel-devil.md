# Angel / Devil 호출 기준

## Angel (생각 확장자)

### 호출 O
- 하나의 접근법만 고려 중일 때
- 대화가 같은 곳을 맴돌 때
- "다른 방법 없나?" 느낌일 때
- 사용자가 직접 요청할 때

### 호출 X
- 아이디어가 충분히 발산됐을 때
- 수렴/정리 단계일 때
- 습관적으로 매번

## Devil (냉철한 비판자)

### 호출 O
- 방향이 잡혔는데 구멍이 있을 수 있을 때
- 범위가 계속 커질 때 ("이것도 하고 저것도")
- 기술적 실현 가능성이 불확실할 때
- 정리 직전 최종 검증으로
- 사용자가 직접 요청할 때

### 호출 X
- 아이디어 초기 단계 (발산을 죽임)
- 사용자가 탐색 중일 때
- 습관적으로 매번
