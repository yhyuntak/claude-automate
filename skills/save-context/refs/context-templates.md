# 세션 컨텍스트 템플릿

## 공통 헤더 (모든 케이스)

```markdown
# Session: {topic} (YYYY-MM-DD)

## 상태: {implement | planning | brainstorm | 자유 대화}
## Plan: .claude/plans/{date}-{slug}.md (있으면)
## 다음 행동: {next_action — 다음 세션에서 첫 번째로 할 일}
```

---

## 1. implement 중

```markdown
## 마지막 동작 상태
- {어디까지 동작하는가}

## 진행 중 AC
- {현재 작업 중인 AC + 어디까지 했는지}

## 이슈 / 메모
- {발생한 문제, 임시 처리}
```

AC 목록은 plan 파일 참조. 중복 저장 안 함.

---

## 2. planning 중

```markdown
## 탐색 결과
- {발견한 패턴/제약 — 파일 경로가 아니라 findings}

## 설계 결정
- {결정 + 근거}

## 기각된 대안
- {검토했지만 버린 것 + 이유}

## 미결정
- {아직 정하지 못한 것 + 뭘 더 봐야 하는지}
```

---

## 3. brainstorm 중

```markdown
## 원래 문제
- {왜 이 브레인스토밍을 시작했는지}

## 아이디어 / 결정
- {논의 내용 + 근거}

## 보류
- {나중에 할 것 + 보류 이유}

## 다음에 이어갈 것
- {미완성 논의}
```

---

## 4. 자유 대화

```markdown
## 배경
- {왜 이 대화가 시작됐는지}

## 결정사항
- {합의한 것 + 근거}

## TODO
- {해야 할 것}
```
