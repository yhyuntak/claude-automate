# AI+TDD 전략

> brainstorm→AC→테스트→구현 워크플로우에서 TDD 적용 기준과 방법 정립

---

## User Story

CA 사용자가 brainstorm에서 도출한 AC의 명확도에 따라 TDD 적용 여부가 자연스럽게 결정되어, 테스트가 "사람의 의도"를 코드 기준으로 고정시킨다.

## Acceptance Criteria

- [ ] AI 코딩 환경에서 테스트 레벨별 가치 분석 (Unit < Integration < Acceptance)
- [ ] /brainstorm → AC 추출 확장 가능성 검토
- [ ] TDD 적용 기준 정립 (AC 명확도 기반 자동 판별)
- [ ] 결정: 도입 여부 및 /brainstorm 스킬 수정 범위
