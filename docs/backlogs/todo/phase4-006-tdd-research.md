# AI 시대 TDD 실전 리서치

> AI 코딩 환경에서 TDD/테스트 전략에 대한 실전 후기와 패턴 수집

---

## User Story

AI 코딩 시대에 TDD를 어떻게 적용하는지 실전 후기와 패턴을 수집하여, 우리 하네스의 테스트 전략을 수립한다.

## Acceptance Criteria

- [ ] AI + TDD 실전 후기 수집 (블로그, 해커뉴스, Reddit 등)
- [ ] 프로토타입 → 프로덕션 전환 시 테스트 전략 사례 조사
- [ ] "테스트 먼저 vs 검증 스크립트 vs 나중에 추가" 각 접근법의 장단점 정리
- [ ] AI에게 테스트를 쓰게 할 때의 함정과 해결책 조사
- [ ] 우리 하네스에 적용할 테스트 전략 초안 도출

## 조사 관점

- 프로토타입 단계에서 TDD는 관리 부담이 되는가?
- AI가 테스트를 쓸 때 "틀린 테스트가 틀린 코드를 통과"하는 문제의 실전 사례
- 프로토타입 → 프로덕션 경계에서 테스트를 도입하는 현실적 기준
- Level 0(없음) → Level 1(검증 스크립트) → Level 2(핵심 경로) → Level 3(전체 TDD) 단계적 접근 사례
